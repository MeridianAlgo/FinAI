  HOW TO REPLACE THE MODEL ON HUGGING FACE
═══════════════════════════════════════════════════════════════

OPTION 1: Automatic Upload (Recommended)
─────────────────────────────────────────

1. Get your Hugging Face token:
   - Go to: https://huggingface.co/settings/tokens
   - Copy your token (or create new one with WRITE access)

2. Set the token in your terminal:
   
   Windows (PowerShell):
   $env:HF_TOKEN="your_token_here"
   
   Mac/Linux:
   export HF_TOKEN=your_token_here

3. Run the upload script:
   python force_upload_new_model.py

4. Done! The script will:
   ✓ Delete old model files
   ✓ Upload new v2.0 model
   ✓ Update README

═══════════════════════════════════════════════════════════════

OPTION 2: Manual Upload (If script fails)
─────────────────────────────────────────

1. Go to: https://huggingface.co/MeridianAlgo/Fin.AI/tree/main

2. Delete these old files:
   - model.pt
   - config.json  
   - README.md

3. Click "Add file" → "Upload files"

4. Upload these files from checkpoints/model/:
   - model.pt (121 MB)
   - config.json
   - README.md

5. Commit message: "v2.0.0 - Fresh model initialization"

TROUBLESHOOTING
─────────────────────────────────────────

Problem: "Authentication failed"
Solution: Check your HF_TOKEN has WRITE access

Problem: "File too large"
Solution: Use git-lfs (already configured in repo)

Problem: Script fails
Solution: Use manual upload method instead
