# Security Policy

## Supported Versions

Use the latest version of FinAI for the most secure experience.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability, please report it responsibly:

1.  **Do not** open a public issue.
2.  Email us at `security@meridianalgo.com` (or the maintainer's email).
3.  Include details about the vulnerability and how to reproduce it.

We will acknowledge your report within 48 hours and work to resolve the issue as quickly as possible.
