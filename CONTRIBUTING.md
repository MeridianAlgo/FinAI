# Contributing to FinAI

Thank you for your interest in contributing to FinAI! We welcome contributions from the community to make this the best financial AI model.

## How to Contribute

1.  **Fork the Repository**: Click the "Fork" button on the top right of the repository page.
2.  **Clone your Fork**: `git clone https://github.com/YOUR_USERNAME/FinAI.git`
3.  **Create a Branch**: `git checkout -b feature/amazing-feature`
4.  **Make Changes**: Implement your feature or fix.
5.  **Test**: Ensure your changes work as expected.
6.  **Commit**: `git commit -m "Add amazing feature"`
7.  **Push**: `git push origin feature/amazing-feature`
8.  **Open a Pull Request**: Submit your PR to the `master` branch.

## Guidelines

*   **Code Style**: Follow standard Python (PEP 8) guidelines.
*   **Documentation**: Update documentation if you change functionality.
*   **Datasets**: If adding a dataset, ensure it is public and compatible with Hugging Face `datasets` library.

## Reporting Issues

If you find a bug or have a feature request, please open an issue on the GitHub repository.
